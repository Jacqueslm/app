# KEYWORDS — the only source of search truth

Pulled live from Semrush (US database) on **6 Aug 2026**, the last pull before
the connector goes away. This file is **final** — no re-running research, no
fresh volumes, no estimating numbers that aren't here. Terms are tagged:

- **Build** — write for it (script, title, page, caption). The tag already
  weighs volume, difficulty, intent, and whether the app can honestly answer.
- **Too hard** — real demand, but a one-person site won't rank; don't chase it
  with pages. (KD = keyword difficulty, 0–100.)
- **Skip** — wrong intent, a competitor's navigational search, or something the
  app can't honestly claim. Volume never overrides a Skip.

Vol = US searches/month. KD = difficulty. Blank KD = Semrush had no score
(usually tiny volume).
