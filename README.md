# lesson-audio

Pre-generated lesson narration for Turn Someday Into Day One - five Piper
voices per lesson, served to the app straight from raw.githubusercontent.com.
Never merge this branch. Regenerate with TurnSomeDayIntoOneday/tools/
generate-lesson-audio.py on main; file names are content-hashed, and the app
finds them via data/lesson-audio-manifest.json committed on main.
