📅 Connect Buffer

Buffer is where your posts get queued. Make a key at publish.buffer.com/settings/api (Settings → API — free accounts get one key, paid get five, and you must be the account owner), then paste it here. Connecting only reads which channels you have; nothing gets posted.
Buffer's API is still an invite-only beta. If the key page is missing, or a saved key keeps failing with 401, your account probably hasn't been granted API access yet — request it from Buffer, because no amount of fixing on this end gets round that.
If it fails: ⚙ Settings → Diagnostics → 🧹 Clear the list, come back, press Test again, then screenshot Diagnostics. Buffer's exact words land there now.
