# Handover — the search research

For whoever picks up SEO, content or marketing next. Written 15 Aug 2026.

## There is one file and it is `KEYWORDS.md` in the repo root

476 lines. Every search number this project owns is in it. Read it before
writing a page, a video title, a caption or an ad.

## The single most important thing

**The Semrush subscription has ended. There is no way to pull a new number.**

Everything in `KEYWORDS.md` came from live US-database pulls on **6, 10 and 12
August 2026**, verified against the API before saving, with the two 6 Aug pulls
cross-checked against each other on every overlapping term.

That means three rules, and they are not stylistic:

1. **Quote the numbers in that file. Never re-estimate them.** A volume you
   reasoned your way to is not data, and it will get written into a plan as if
   it were.
2. **A term missing from the file is not proof the term is unclaimed.** It may
   simply never have been pulled. Say "not measured", never "no competition".
3. **Do not re-run the research.** You cannot. Do not open a trial, and do not
   substitute a different tool's numbers into a file whose whole value is that
   one source produced all of it consistently.

If a decision genuinely needs a number that isn't there, the honest move is to
say so and decide without it.

## What is in the file

- **The seven tracked keywords** — Position Tracking is capped at seven on the
  free plan, so these seven are the entire search scoreboard. All difficulty 27
  or under, ~1,420 searches a month between them, all in Lane 1.
- **Eight lanes**, each a table of terms tagged **Build** / **Too hard** /
  **Skip**. The tag already weighs volume, difficulty, intent, and whether the
  app can honestly answer the query — so the tag beats the volume column every
  time. A high-volume Skip is still a Skip.
- **A page plan**, in build order.
- **A coverage check** across all 13 habit tracks in the app.
- **Question terms** and a **final pull** (12 Aug), including **Lane 8, "dry
  drunk"** — ~11,700/mo at difficulty 30–34, and the closest match in the whole
  dataset to what Jacques actually lived.

## The finding that shapes everything

The first tracking run used broad head terms and returned **zero across the
board** — samhsa.gov, Wikipedia and drugs.com hold the top of every one of those
SERPs. Those results are not hard, they are **closed**: Google fills health
queries with institutional sources and a one-person site does not displace a
government agency.

**Nobody institutional writes for the person who *loves* an addict.** That is
why Lane 1 is winnable when the head terms are not, and it is the same audience
that outperforms everything else on TikTok and Facebook. If a plan you write
drifts back toward head terms like "how to stop drinking", you have re-made the
mistake this file exists to record.

## How to use it, in one line

**Videos:** any Build term is a title, said out loud the way the term is
written. **Pages:** follow the page plan in order.
