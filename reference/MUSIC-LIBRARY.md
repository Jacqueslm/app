# Music library — what each track is and where it goes

One card per track. Add a card the day a track arrives, not later — nine
instrumental beds all called "underscore" are impossible to tell apart in a
library list a week from now.

**How to fill in the "Sound" line:** whoever adds the card usually cannot listen
to the file (Claude can read a file's length and format, not hear it). So Sound
is Jacques's line. Everything above it is measured from the file.

## Face Yourself

| | |
|---|---|
| **File** | `Face_Yourself.mp3` |
| **Length** | ~15 seconds |
| **Format** | MP3, small file — a clip or a hook, not a full track |
| **Sound** | *(Jacques to fill in)* |
| **Vocals?** | *(assumed yes, from the title — confirm)* |
| **Use for** | Not narration episodes. See below. |

**Where this can and cannot go.** If it has a vocal, it cannot sit under any of
the nine episodes — words under narration means two voices competing and the
viewer hears neither. A vocal track needs a piece with **no narration**: a
milestone montage, a wordless cut with on-screen text only, or the last three
seconds behind a CTA card.

At ~15 seconds it is a sting, not a bed. That is a real use, not a lesser one:
a 15-second hook is exactly the length of an intro under a title card, or a
standalone short with three lines of on-screen text and nothing spoken.

## Low Pitch Symphony Underscore

| | |
|---|---|
| **File** | `Low_Pitch_Symphony_Underscore.wav` |
| **Length** | 1 minute 40 seconds |
| **Format** | WAV, stereo, 48kHz 16-bit — uncompressed, 19 MB |
| **Sound** | *(Jacques to fill in)* |
| **Vocals?** | No — it is an underscore |
| **Use for** | **Episode 8, The Empty Chair** (substances / spiritual) first choice. Also fits **Episode 1, The Gambler**. |

**Why those two.** Both are built on dread that arrives quietly rather than
loudly — a man adding up bank statements, a man not getting out of a car. A low
sustained bed does that work without asking the viewer to feel anything
specific. It would fight the warmer episodes (The Hoodie, The Second Dinner),
which need something with a pulse.

**It is long enough for any episode.** Ten shots at 5 seconds is 50 seconds plus
a 3-second card — 53 in total, so this covers a full episode with 47 seconds
spare. Use **🎯 Fit shots to song length** only if you want the film stretched
to the whole track; otherwise let it run under and fade.

**One practical note on the WAV.** 19 MB uncompressed is fine for editing and
wasteful to keep many of. Studio handles it either way, but if you end up with
a dozen WAV beds, that folder grows fast — the auto-backup only covers the
database, not the media folder.

## Manus-generated tracks — Jacques's call, 15 Aug 2026

Manus generates a bespoke instrumental per episode from the Suno-style brief
(the first was `slow_hymnal_instrumental_53s.wav`, 53s — exactly ten shots at
five seconds plus the three-second card).

Manus's own disclaimer: it cannot guarantee the output is copyright-free or
cleared for commercial use. **Jacques has decided to use them anyway unless
something gets flagged.** That is a reasonable bet and it is his to make — do
not re-litigate it every session.

What that decision requires, and it is the only obligation:

- **Keep the generation record** for each track: the prompt, the output file,
  and the date. That is the only thing that helps if anyone ever asks.
- **If a track gets flagged** — a Content ID match on YouTube, an audio claim on
  TikTok — the consequence is a muted video or redirected ad revenue, not a
  strike. Swap the track, re-upload, move on.
- **Keep a Suno version as the backup** for any episode carrying a Manus track.

**Jacques pays for Suno**, so tracks generated *while subscribed* carry
commercial rights. Rights are not retroactive: anything made before the
subscription started is not covered, and re-generating it is the fix.
