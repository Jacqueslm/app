# OUTREACH — the 18 remaining form targets, in click order

Companion to `OUTREACH.md`. Same targets, same numbers — this one exists only
so a Tuesday session is click → paste → submit → next, instead of hunting for
each site's contact page.

**The body text lives in `OUTREACH.md` under the matching number.** Only the
subject is repeated here, because that is the line that goes first in the
message box.

Reminder of the form rules from `OUTREACH.md`: required fields only, subject
as the first line of the message box, body underneath, and never pick
"admissions" in a dropdown — general enquiry, media, partnership or other.

Tick the box in `OUTREACH.md` as each one goes.
