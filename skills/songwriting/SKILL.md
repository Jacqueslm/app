# Songwriting Skill

Use this skill whenever the user asks to write a song, lyrics, or a prompt for a music-generation tool.

## What to deliver

- When asked to **write a song**, write complete, original lyrics, not only a description or a prompt.
- When useful, include clear sections such as `[Intro]`, `[Verse]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, and `[Outro]`.
- When asked for Suno or another music-generation tool, provide a separate, ready-to-paste **Style of Music** prompt. If the user asks for both lyrics and a Suno prompt, provide both in separate labeled blocks.
- Keep the result easy to copy, download, or paste into the tool. Do not claim text is an audio file or that a song has been generated unless it actually has.

## Suno prompt delivery

When the user asks for a Suno prompt:

- Write the ready-to-paste prompt into a plain-text `.txt` file, with the prompt itself clearly labeled and no unrelated explanation mixed into the text.
- Provide the file through the platform's actual downloadable-file or attachment mechanism. Do not present a repository path as a download link if opening it treats the filename as a project or repository route.
- Also include the prompt inline in one fenced text block so it remains easy to copy if the file link does not work.
- If a real downloadable attachment cannot be created in the current interface, say so plainly and provide the complete prompt in the copyable text block instead. Never claim that text is generated audio or a downloaded song.

## Creative direction

For themes of self-discovery, healing, and winning in life:

- Tell a personal-feeling story: facing setbacks, learning self-trust, letting go of what holds the narrator back, finding purpose, and celebrating progress.
- Make the confidence feel earned and grounded, not arrogant or sugary.
- Favor vivid, concrete details, natural phrasing, memorable rhythmic lines, and a catchy, singable or chantable hook.
- Give the song an emotional arc: reflection, decision, growth, and release or celebration.
- Avoid generic clichés and filler. Do not force every theme into every song; follow the user's requested subject and mood.

## Genre and originality

- Respect the genre and production traits the user requests. For Jersey club, a useful broad palette can include a brisk, bouncy dance groove, syncopated kicks, crisp claps, deep controlled bass, call-and-response vocals, chant-style hooks, and short dropouts or fills. Treat tempo suggestions as optional unless the user specifies them.
- Make lyrics, melodies, hooks, vocal cadence, and production details original.
- Do not copy lyrics or closely imitate a named artist, song, or recording. If the user provides a reference track, use broad genre-level characteristics rather than reproducing distinctive details.

## Interaction

- Answer the request directly. If the user says “write the song,” write the lyrics rather than another prompt about how to write them.
- Do not ask follow-up questions if a reasonable first version can be created from the context. Make sensible creative choices and invite revisions only after delivering the work.
